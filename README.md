# Наради

Веб-додаток (PWA) для запису нарад, розпізнавання тексту кількома двигунами на вибір, підсумків і задач.
Працює на телефоні (Android), Windows і Mac з одного посилання; дані синхронізуються через особистий Google-акаунт.

## Що вміє

- Календар нарад, синхронізований з Google Календарем; учасники з довідника «Люди».
- Запис з мікрофона (екран не гасне, записане зберігається кожні 5 с) або завантаження файлу з диктофона.
  На Android: Диктофон → Поділитися → «Наради».
- Стиснення в браузері: моно 16 кГц, MP3 32 кбіт/с (≈14 МБ на годину), нарізка довгих записів по паузах.
- Двигуни розпізнавання: Gemini, Groq Whisper, OpenAI, ElevenLabs Scribe. Можна запустити кілька й порівняти.
- Підписування спікерів іменами, підсумок, рішення, задачі (Gemini, OpenAI або Claude), Google Doc у папці наради.

## Будова

| Частина | Де | Що робить |
|---|---|---|
| `index.html`, `app.css`, `js/`, `sw.js`, `manifest.webmanifest` | GitHub Pages | Інтерфейс, запис, стиснення, виклики двигунів |
| `vendor/lame.min.js` | GitHub Pages | Кодувальник MP3 (LAME, LGPL) |
| `backend/Code.gs`, `backend/appsscript.json` | Google Apps Script | Таблиця нарад, Диск, Календар, ключі API, Google Doc |

Ключі API зберігаються у властивостях скрипта Google, а не в коді. У репозиторії немає жодних ключів чи даних.

## Дані на Google Диску

- Папка «Наради — записи»: таблиця «Наради — база» (аркуші «Наради», «Люди», «Словник») і папка на кожну нараду
  з аудіо, текстами двигунів (`transcript_*.json`), підсумком (`analysis.json`) і Google Doc.
- Календар «Наради» (можна змінити в Налаштуваннях додатку).
