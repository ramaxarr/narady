# Наради

Веб-додаток (PWA) для запису нарад, розпізнавання тексту кількома двигунами на вибір, підсумків і задач.
Працює на телефоні (Android), Windows і Mac з одного посилання; дані синхронізуються через особистий Google-акаунт.

## Що вміє

- Календар нарад, синхронізований з Google Календарем; учасники з довідника «Люди».
- Запис з мікрофона (екран не гасне, записане зберігається кожні 5 с) або завантаження файлу з диктофона.
  На Android: Диктофон → Поділитися → «Наради».
- Стиснення в браузері: моно 16 кГц, MP3 32 кбіт/с (≈14 МБ на годину), нарізка довгих записів по паузах.
- Двигуни розпізнавання: Gemini, Groq Whisper, OpenAI, ElevenLabs Scribe. Можна запустити кілька й порівняти.
- Підписування спікерів іменами, підсумок, рішення, задачі (Gemini, OpenAI або Claude), Google Doc у папці наради.
- Автоматичні імена спікерів: мітки ElevenLabs і OpenAI (speaker_0, 1·A…) підписуються іменами за збігом слів з текстом Gemini;
  якщо текст ElevenLabs майже весь з іменами — він стає основним для підсумку. Є й кнопка «Підписати» в «Хто є хто».
- ElevenLabs у фоні отримує весь запис одним завданням (до 90 хв), тож мітки спікерів наскрізні; якщо сервіс не прийме
  завдання — запис обробляється частинами по ~15 хв, а причину видно в попередженні.
- Повторювані наради: серії в Google Календарі (робочі дні, щотижня, раз на 2 тижні, щомісяця) на обраний термін.
- Задачі з усіх нарад в одному списку: виконано / прострочено, терміни датами, текст для тижневого звіту.
- Відкриті задачі з минулих нарад серії — у порядку денному наступної; підсумок підказує, про що звітували як виконане.
- Пошук по всіх розшифровках і підсумках з переходом на потрібний момент запису.
- Фонова обробка (скрипт 1.2.0+): запис зберігається на Диск частинами по ~5 хв, розпізнавання, підсумок і документ
  робить скрипт Google — після завантаження додаток можна закрити. Поки додаток відкритий, він підганяє обробку сам;
  коли закритий — скрипт продовжує за тригером (ліміт Google — 90 хв роботи тригерів на добу).
  Галочка «Обробляти у фоні» в діалозі запуску; без неї обробка йде на пристрої, як раніше.

## Будова

| Частина | Де | Що робить |
|---|---|---|
| `index.html`, `app.css`, `js/`, `sw.js`, `manifest.webmanifest` | GitHub Pages | Інтерфейс, запис, стиснення, виклики двигунів |
| `vendor/lame.min.js` | GitHub Pages | Кодувальник MP3 (LAME, LGPL) |
| `backend/Code.gs`, `backend/appsscript.json` | Google Apps Script | Таблиця нарад, Диск, Календар, ключі API, Google Doc |

Ключі API зберігаються у властивостях скрипта Google, а не в коді. У репозиторії немає жодних ключів чи даних.

## Дані на Google Диску

- Папка «Наради — записи»: таблиця «Наради — база» (аркуші «Наради», «Люди», «Словник», «Серії», «Задачі») і папка на кожну нараду
  з аудіо (одним файлом або частинами `… — 01.mp3`, `audio.json`), текстами двигунів (`transcript_*.json`), підсумком (`analysis.json`),
  станом фонової обробки (`job.json`) і Google Doc.
- Календар «Наради» (можна змінити в Налаштуваннях додатку).
